Install

Provisions on first run, not on npm install. npm 12 disables postinstall scripts.

npx agentsean
curl -fsSL https://raw.githubusercontent.com/vp2722/sean/main/install/install.sh | sh
SEAN_AUTH_TOKEN="$(openssl rand -base64 32)" docker compose up

Then: sean doctor. To survive reboot: sean service install — it prints the files it will write. That command is never a side effect of npm.

Node ≥ 22.19. Chromium is downloaded lazily on first JS render.
