Fix title tags on WordPress

Sean writes unique titles through the companion plugin, verifies live HTML, and stores a revert snapshot.

  1. Install sean-bridge and create an Application Password.
  2. sean connect wordpress --api-key USER:APP_PASSWORD https://example.com
  3. sean apply — T1 title-tag Actions apply automatically after the observe window.
  4. Click Revert on any change. The shadow ledger restores the previous post meta.
